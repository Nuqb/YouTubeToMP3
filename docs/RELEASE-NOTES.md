## Download & open (Windows 10/11, 64-bit)

1. Download **YouTubeToMP3-Windows-x64.zip** from Assets below.
2. Right-click the ZIP → **Extract All**.
3. Open the extracted **YouTubeToMP3** folder and double-click **YouTubeToMP3.exe**.

The converter opens in your browser. Paste a link → **Convert** → **Download .mp3**.
Keep the launcher window open while using the converter; close it when finished.

**No Git, Python, FFmpeg installation, or administrator access needed.** Keep the
whole extracted folder together, including `_internal`. Internet access is required.

This first portable Windows release includes a desktop launcher, bundled conversion
tools, automatic browser opening, a free local port, and a visual quick-start README.

### Notes

- The release is unsigned; Windows may display an unknown-publisher warning. Only run downloads you trust. Do not disable antivirus protection.
- Save converted files within 30 seconds before temporary cleanup.
- Spotify and Beatstars links search YouTube for a match. Restricted content and platform blocks may prevent conversion.
- macOS/Linux users can run from source using the README's developer instructions.
- `SHA256SUMS.txt` provides a checksum. The **Source code** archives are for developers; use the Windows ZIP to run the app.
